# O modelo das cinco camadas

A NVIDIA descreve a stack de IA como um bolo de cinco camadas: infraestrutura de computação (GPUs e rede), plataforma de dados, modelos de fundação, plataforma de desenvolvimento de aplicações de IA e, no topo, as aplicações que o usuário vê. Cada camada consome a de baixo e habilita a de cima.

# Leitura para diagnóstico de startups

O modelo serve de régua de diagnóstico: uma startup que opera apenas na camada de aplicação, consumindo modelos de terceiros por API, tem toda a sua base fora do próprio controle. Descer camadas de forma seletiva — servir o próprio modelo, otimizar inferência, organizar a plataforma de dados — converte custo variável em ativo técnico e reduz dependência de fornecedores.

# Uso na justificativa de negócio

Ao recomendar tecnologia, o mapa de camadas explica o porquê em linguagem de negócio: cada recomendação posiciona a empresa em uma camada específica e diz qual dependência externa ela internaliza. É vocabulário de explicação, não tecnologia a adotar — as recomendações concretas continuam vindo das dezesseis tecnologias do portfólio.
